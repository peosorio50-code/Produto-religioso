# Como instalar a skill "produto-digital"

**No seu Mac (vale para todos os repositórios no Claude Code):**
```
mkdir -p ~/.claude/skills && unzip -o skill-produto-digital.zip -d ~/.claude/skills
```
Depois, abra o Claude Code em qualquer pasta e peça, por exemplo: "use a skill produto-digital e monte um produto novo". Também dá para chamar direto com `/produto-digital`.

**Num repositório específico (vale também nas sessões na nuvem do claude.ai/code):** copie a pasta `produto-digital` para `.claude/skills/` dentro do repositório e faça o commit.

**Para atualizar:** troque a pasta inteira pela versão nova (por exemplo, quando o manual do Meu Santo mudar, substitua `references/manual-meu-santo-protetor.md`).
